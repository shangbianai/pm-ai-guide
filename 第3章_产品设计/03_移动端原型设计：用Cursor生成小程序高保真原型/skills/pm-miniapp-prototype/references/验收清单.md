# AI 原型设计验收清单

## 需求与结构

- [ ] 页面是否服务明确的用户任务。
- [ ] 是否有清晰的信息架构。
- [ ] 小程序和后台是否拆成两个独立项目。
- [ ] 两端是否共享同一套商品、订单、会员、活动、门店口径。

## 交互与状态

- [ ] 主流程是否可点击走通。
- [ ] 导航是否能切换。
- [ ] 后台左侧菜单是否能收纳。
- [ ] 表格行是否能打开右侧详情抽屉。
- [ ] 是否覆盖默认、加载、成功、失败、空态、异常态。

## 保真度

- [ ] 低保真是否只保留结构，避免彩色干扰。
- [ ] 高保真是否有真实内容密度。
- [ ] 图片、图标、价格、商品、订单、会员数据是否可信。

## 后台质量

- [ ] 运营总览是否展示商品、订单、会员、门店、活动等全局统计。
- [ ] 商品管理是否包含分类、筛选、列表、添加商品、库存调整。
- [ ] 订单履约是否包含状态流转、异常处理和门店协同。
- [ ] 会员运营是否包含分层、标签、发券和历史订单。
- [ ] 门店管理是否包含营业状态、公告、营业时间和取餐能力。

## 交付

- [ ] 是否提供 HTML 文件。
- [ ] 是否提供压缩包。
- [ ] 是否提供项目规则 MD。
- [ ] 是否提供用户规则 MD。
- [ ] 是否提供提示词模板。
- [ ] 是否提供验收清单。
