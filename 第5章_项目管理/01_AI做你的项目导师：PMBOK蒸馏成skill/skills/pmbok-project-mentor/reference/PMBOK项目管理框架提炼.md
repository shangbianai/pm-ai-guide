# PMBOK 项目管理框架提炼

本文件用于课程和 Skill 的高层参考，不复制原书正文。

## 五大过程组

- 启动：明确商业目标、项目章程、核心干系人。
- 规划：拆范围、排进度、估资源、定风险和沟通机制。
- 执行：组织团队完成交付，并同步处理协同和质量问题。
- 监控：跟踪偏差、处理变更、维护风险清单。
- 收尾：完成验收、移交、复盘和经验沉淀。

## 十大知识领域

整合、范围、进度、成本、质量、资源、沟通、风险、采购、相关方。

## 产品经理常用转换

- 项目章程 -> 目标、边界、成功标准。
- WBS -> 功能拆解、任务拆解、交付物拆解。
- 进度管理 -> 关键路径、里程碑、延期预警。
- 风险管理 -> 风险登记册、触发信号、应对动作。
- 相关方管理 -> 权力利益矩阵、沟通节奏、决策升级。
