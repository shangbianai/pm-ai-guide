## 统一案例

`/统一教学案例` 使用清晰标注的教学模拟数据，展示“智能制造设备预测性维护平台”如何从需求结构走到产品架构。

## 安装

将对应 `skills/<skill-name>` 目录复制到 Codex Skills 目录，然后重新开启会话。也可把完整目录发给 Codex，要求它按 `SKILL.md` 安装。
