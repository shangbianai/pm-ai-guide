Case

示例网站：树根互联 GYPT

这次选择树根互联的 GYPT 产品页作为调研对象。它适合训练“工业互联网 / AI 工业应用 / 企业级平台”方向的竞品分析。

目标不是评价树根互联本身，而是训练一种调研方式：让 Agent 先读网页，再抽取竞品分析所需的信息。
https://www.irootech.com/product/gypt.html
工业 AI 与数字化平台
Workflow

Agent 竞品调研的 5 步流程

1给网址让 Agent 打开目标官网。
2提取信息定位、功能、价格、案例、CTA。
3补竞品列出同类产品和替代方案。
4建矩阵按统一维度横向对比。
5给建议输出差异化机会和下一步验证。
Tools

龙虾、OpenClaw、Hermes 怎么分工？

你可以把它们理解成不同风格的 Agent 工作台：核心不是工具名字，而是它们都能承接“打开网页、执行搜索、整理材料、生成文档”的任务。

龙虾

适合快速给任务、看结果，做轻量调研入口。

OpenClaw

适合浏览器自动化、网页操作和多步骤执行。

Hermes

适合把调研拆成任务，持续补资料和产出结构化报告。

Prompt

实操输入模板

把网址、分析目的、输出格式告诉 Agent。先不要要求它写长文，先要求它抽取结构，再让它补充竞品和机会点。

目标网站：https://www.irootech.com/product/gypt.html 产品：树根互联 GYPT 行业：工业互联网 / AI 工业应用 / 企业级数字化平台 目的：做一份竞品调研底稿，找出产品定位、核心能力、目标客户和差异化机会 请输出： 1. 官网信息提取 2. 可能的竞品列表 3. 功能对比维度 4. 机会点与风险 5. 下一步需要验证的问题
Output

输出不要只要“总结”，要要“判断”

模块Agent 要提取什么产品经理要判断什么
定位产品口号、目标用户、核心场景它到底服务谁？
功能AI、工作流、权限、数据分析、模板哪些能力是差异化，哪些是标配？
转化免费试用、预约咨询、案例入口它怎么引导用户进入销售或试用？
竞品同类产品和替代方案我们应该和谁比，而不是和谁都比。
机会页面没有讲清楚或用户可能担心的点我们能不能在表达、功能或服务上切入？
Review

回顾重点：这节案例有什么价值

第一，掌握用 网址启动竞品调研 的方式。

第二，理解从网页信息到 竞品矩阵和机会点 的流程。

第三，记住 Agent 输出只是底稿，真正有价值的是产品经理补上的 业务判断。
