# AI 增强型产品经理课程 HTML 聚合页

这是课程全部 HTML 课件和交互 Demo 的统一入口，按产品经理工作流和课程章节整理。

## 本地打开

直接打开 `index.html`，或在当前目录启动静态服务器：

```bash
python3 -m http.server 8014
```

访问：`http://127.0.0.1:8014/index.html`

## 内容

- 32 个课件及 Demo 入口
- 7 个课程章节
- 章节筛选和关键词搜索
- 飞书课程知识库入口
- GitHub 课程仓库入口

## 字体与素材

页面使用开源字体 `LXGW WenKai / 霞鹜文楷`。课程封面缩略图均来自本地真实 HTML 课件。
