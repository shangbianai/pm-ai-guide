# PRD 质量检查清单

输出 PRD 前逐项检查：

- 是否包含文档信息、版本历史和修订记录？
- 是否说明文档目的、适用范围、读者对象和参考资料？
- 是否有名词解释，避免业务术语歧义？
- 是否说明背景、目标、成功指标、风险和约束？
- 是否明确本期范围、不做范围、前置依赖和后续规划？
- 是否列出用户角色、权限边界和使用场景？
- 是否包含主流程、异常流程和状态流转？
- 是否有功能总览，并标注优先级和使用角色？
- 每个核心功能是否包含功能描述、入口权限、页面说明、页面元素表、业务规则、业务逻辑和验收标准？
- 是否覆盖数据字段、数据口径、接口或系统依赖？
- 是否包含性能、安全、权限、兼容、日志审计、法务财务等非功能需求？
- 是否说明上线、灰度、回滚、下线和运营支持？
- 是否列出待确认问题，而不是编造缺失规则？
- 是否删除泛泛的 AI 式表达，改成具体规则、字段、流程和判断？
