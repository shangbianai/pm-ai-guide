# 中国公文排版格式标准

> 参考 GB/T 9704-2012《党政机关公文格式》

## 页面设置

纸张：A4（210mm × 297mm）。页边距分两套，按场景选：

| 边距 | 通用 A4（默认） | 严格公文版心（GB/T 9704） |
|------|----------------|--------------------------|
| 上（天头） | 2.54 cm | 3.7 cm |
| 下（地脚） | 2.54 cm | 3.5 cm |
| 左（订口） | 3.18 cm | 2.8 cm |
| 右（切口） | 3.18 cm | 2.6 cm |

- **通用 A4**：申报书 / 标书 / 方案等非公文材料的常见选择 → `make_reference.py ref.docx generic`
- **公文版心**：正式党政机关公文，或评审明确要求 GB/T 9704 时 → `make_reference.py ref.docx gb`（版心 156×225mm）

> 注意：字体字号那套（仿宋三号正文 + 黑/楷/仿三号标题）两种边距下都一样、都符合公文字体规范；区别只在页边距。

## 字体层级

| 层级 | 中文字体 | 英文字体 | 字号 | 加粗 | 对齐 |
|------|---------|---------|------|------|------|
| 封面标题 | 方正小标宋简体 | Times New Roman | 二号（22pt） | 是 | 居中 |
| 一级标题（章） | 黑体 | Times New Roman | 三号（16pt） | 是 | 左对齐 |
| 二级标题（节） | 楷体 | Times New Roman | 三号（16pt） | 是 | 左对齐 |
| 三级标题 | 仿宋 | Times New Roman | 三号（16pt） | 是 | 左对齐 |
| 正文 | 仿宋 | Times New Roman | 三号（16pt） | 否 | 两端对齐 |
| 表格内容 | 宋体 | Times New Roman | 五号（10.5pt） | 否 | — |
| 表格表头 | 黑体 | Times New Roman | 五号（10.5pt） | 是 | — |
| 图片题注 | 宋体 | Times New Roman | 小五号（9pt） | 否 | 居中 |

## 段落格式

| 参数 | 值 |
|------|-----|
| 正文行距 | 固定值 28 磅 |
| 标题行距 | 字号 + 12 磅 |
| 正文首行缩进 | 2 字符 |
| 标题首行缩进 | 无 |
| 段前段后间距 | 6 磅 |
| 标题段前段后间距 | 6 磅 |

## 表格规范

- 使用三线表：顶线（1.5pt）、表头下线（1pt）、底线（1.5pt），无线框
- 表内文字不缩进
- 表格居中
- 表头加粗，黑体，五号
- 表体宋体，五号
- 表内行距：至少 22 磅
- 表题（表格上方的标题）和表注（表格下方的说明）用宋体小五号

## 图片规范

- 插图宽度：12-14.5 cm
- 分辨率：≥ 300 dpi
- 图片居中，无缩进
- 图片段落行高：自动（非固定值），否则图片会被截断
- 图片前留 6pt 间距，后留 6pt 间距
- 图题（图片下方的编号和标题）居中，宋体小五号

## 标点符号

- 中文正文使用全角标点
- 引号使用中文配对引号：" "（不是 ASCII 直引号 " "）
- 破折号使用 —（em dash），不是 - 或 --
- 书名号使用《》
- 英文、数字、公式使用半角字符

## 页码

- 封面、目录页不标页码
- 正文首页从第 1 页开始
- 页码位置：页面底端居中
- 页码字体：宋体，五号

## 封面

- 标题：方正小标宋简体，二号（22pt），居中，加粗
- 承担单位、日期：仿宋，三号（16pt），居中

## Windows 字体名称对照

在设置 reference.docx 时，东亚字体字段使用以下名称：

| 用途 | Windows 标准字体名 | 备选字体名 |
|------|-------------------|-----------|
| 正文 | 仿宋 | 仿宋_GB2312 |
| 标题H1 | 黑体 | 黑体 |
| 标题H2 | 楷体 | 楷体_GB2312 |
| 表格 | 宋体 | 宋体 |
| 封面 | 方正小标宋简体 | — |

> **注意**：不同 Windows 版本安装的仿宋/楷体可能是 GB2312 版本或新版本。如果 `仿宋_GB2312` 找不到，回退到 `仿宋`。`make_reference.py` 脚本使用 `仿宋_GB2312` 名称但实际渲染时 Windows 会自动匹配。
