# 手绘讨论白板

Skill：`create-discussion-whiteboard`

将会议讨论、领导指令、跨部门沟通或工作坊材料，整理成“已知事实、问题分歧、决策共识、行动计划”四个区域的手绘白板。

> 请使用 `$create-discussion-whiteboard`，把这份设备预测性维护需求讨论记录整理成手绘白板。分成“已知事实、问题分歧、决策共识、行动计划”四个区域，输出可编辑 `.excalidraw`、HTML、PNG 和 JSON。

核心交付物：

- `.excalidraw`：可导入 Excalidraw 继续编辑。
- `SVG / PNG / JPG`：适合文档、课件和汇报。
- `HTML`：浏览器稳定预览。
- `JSON`：保留白板的结构化内容。
