# AI 原型设计提示词模板

## 基础输入

```text
我要做一个产品原型，请先输出实现计划，再开始写代码。

产品名称：
业务场景：
目标用户：
核心任务：
需要输出的端：
- 小程序端
- 后台管理端

保真度：
- 支持低保真
- 支持高保真

交付文件：
- miniapp_prototype.html
- admin_operations_prototype.html
- prototype_project_rules.md
- acceptance_checklist.md
```

## 小程序要求

```text
小程序端要求：
- 手机壳居中，外观接近真实 iPhone Pro Max。
- 左侧是可收起抽屉导航，包含一级功能和多个二级功能。
- 顶部保留小程序胶囊按钮样式。
- 支持高保真 / 低保真切换。
- 首页轮播、换一批、菜单分类、加购、商品规格、订单、会员都要能点击。
- 高保真要有真实图片、商品、价格、订单和会员信息。
- 低保真只保留结构，使用黑白灰。
```

## 后台要求

```text
后台管理端要求：
- 单独 HTML，包含登录、注册和进入管理台。
- 左侧导航支持展开和收纳。
- 运营总览展示全局统计和跨模块风险。
- 商品管理包含分类、筛选、列表、添加商品、库存调整、批量上下架。
- 订单履约包含状态流转、订单列表、异常处理。
- 会员运营包含会员列表、人群分层、发券任务、历史订单。
- 门店管理包含门店卡片、门店列表、营业时间、公告和取餐能力。
- 表格行点击后从右侧弹出详情抽屉。
```
