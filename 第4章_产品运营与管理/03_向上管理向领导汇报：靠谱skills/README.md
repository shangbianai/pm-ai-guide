# 向上管理向领导汇报：靠谱 skills

本章节用于把《靠谱：顶尖咨询师教你的工作基本功》中的工作方法，蒸馏成一个适合产品经理使用的向上管理 Skill。

它适合处理这些场景：

- 向领导汇报项目进展、风险、延期和坏消息。
- 给老板写请示、周报、复盘、会议发言稿。
- 项目推进受阻时，整理事实、判断、方案和需要的支持。
- 客户投诉、需求变更、交付延期、方案争议等场景下，找到更靠谱的表达方式。

## Skill 安装指令

```text
帮我安装这个 skills：
```

## 使用方式

安装后，可以直接把具体工作问题交给 Skill，例如：

```text
我负责的项目延期了，原计划一周上线，但实际至少还需要两周。
老板现在要求一周内上线，我应该怎么跟直属领导沟通延期风险、资源缺口和可选方案？
```

Skill 会优先帮助你整理：

1. 一句话结论。
2. 可直接发给领导的话术。
3. 为什么这样说更靠谱。
4. 还需要补充的事实或数据。
5. 更强硬或更柔和的表达版本。
