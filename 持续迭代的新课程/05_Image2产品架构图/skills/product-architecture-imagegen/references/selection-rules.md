# 风格选择规则

## 明确编号

用户给出 `1`、`01`、`风格8`、`style 15` 等表达时，直接使用对应编号，不重新推荐。

## preview 模式

用户只描述产品、没有选择编号、也没有说“自动”或“直接生成”时：

1. 先生成简洁的 Architecture Brief。
2. 展示 `assets/style-contact-sheet.png`。
3. 提供 `references/style-catalog.md` 与 `references/style-catalog.pdf` 的绝对路径。
4. 请用户选择 `01-16`、`auto` 或 `random`。
5. 当前回合不生成最终架构图。

## auto 模式

用户说“自动、默认、你决定、直接生成、按内容匹配”时，运行：

```bash
python scripts/recommend_style.py --mode auto --text "<用户需求与Architecture Brief>"
```

采用最高分风格；若没有关键词命中，默认使用 `06 居中对称咨询阶梯`。在生成前用一句话告知所选编号及原因，但不再次等待确认。

优先匹配示例：

- 标准产品全景 -> 01 或 06
- AI、模型、数据平台 -> 02
- 政企、国企、蓝图 -> 03
- 能力成熟度、阶段升级 -> 04
- 品牌发布、增长主轴 -> 05
- 高层战略、能力聚合 -> 07
- 模块化、能力复用 -> 08
- 平台生态、伙伴体系 -> 09
- 闭环、飞轮、持续反馈 -> 10
- 中台、组件化 -> 11
- 全栈、硬件到应用 -> 12
- 销售、营销、转化 -> 13
- Agent、工具调用、模型服务 -> 14
- 多角色、多端协同 -> 15
- 双边市场、供需撮合 -> 16

## random 模式

用户明确说“随机、给我惊喜、灵感模式”时，运行：

```bash
python scripts/recommend_style.py --mode random --text "<用户需求>"
```

随机模式仍需排除明显不适配的隐喻：例如单用户内部工具不要强制使用多角色地铁网络；不存在供需双方时不要使用数字桥梁。

## 参考图使用

选择编号后：

1. 读取 `references/style-manifest.json` 获取资产路径和提示词线索。
2. 使用 `view_image` 查看对应 `assets/style-XX.png`。
3. 调用 image 2 时将该图片标记为“风格与构图参考”，不是编辑目标。
4. 在提示词中明确：保留参考图的视觉语法，替换全部产品名称、角色、模块和数据。
